# Rate Limiting

Ключом ограничения служит IP клиента (`$binary_remote_addr`). Зона `partner_api` хранит состояние, базовая скорость равна 10 запросам в минуту. `burst=9 nodelay` позволяет принять пачку до десяти запросов без искусственной задержки; последующие запросы отклоняются с HTTP 429.

Проверка выполнена командой `nginx -t` в контейнере `nginx:alpine`. Функциональный тест из 12 последовательных запросов вернул 429 на запросах 11 и 12:

```text
1–10: upstream response
11: 429
12: 429
```
